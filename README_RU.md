## Исследуйте спрос перед рекламой и подготовкой контента

Узнайте, что ищут пользователи, найдите похожие запросы, сравните регионы и изучите сезонность. Обсуждайте с ИИ группы ключевых фраз, рекламные идеи и содержание сайта на основе полученных данных.

- **Популярные запросы:** фразы с исходными словами и их частотность.
- **Похожие запросы:** ассоциации, которые возвращаются отдельно от популярных фраз.
- **Динамика спроса:** данные по дням, неделям или месяцам за поддерживаемые периоды.
- **Региональный спрос:** сравнение регионов или городов по частотности, доле и индексу интереса.
- **Фильтры устройств:** исследование спроса на компьютерах, смартфонах или планшетах там, где это поддерживается.
- **Собственное подключение:** сохранение API-ключа Yandex Search API и Folder ID в кабинете, выбор активного аккаунта.

В основе этих сценариев четыре команды: популярные запросы, динамика, региональное распределение и справочник регионов. Группировку семантики и контент-план составляет ИИ по полученным данным; отдельной функции кластеризации на сервере нет.

## Три инструмента — подробности по запросу

MCPKit предоставляет ИИ всего три MCP-инструмента: `tool_list`, `tool_help` и `tool_execute`. ИИ может запросить каталог команд, получить подробную справку по нужной команде и выполнить её.

Полные схемы всех команд не включаются в первоначальное описание инструментов. Это экономнее использует контекст, в том числе когда вы обсуждаете другие задачи. Каталог, справка и результаты расходуют токены при запросе; фактическая экономия зависит от ИИ-клиента и диалога.


## Что спросить у ChatGPT

Это примеры запросов, а не результаты клиентов. Используйте исходные фразы на языке аудитории, спрос которой хотите исследовать.

| Задача | Пример запроса |
| --- | --- |
| Первичная семантика | «Подбери популярные запросы со словами “ремонт квартир” по Москве». |
| Смежные темы | «Покажи похожие запросы для “купить диван” и предложи дополнительные темы для исследования». |
| Группы для рекламы | «Получи запросы “доставка цветов” по Москве и предложи группы объявлений на основе полученных фраз». |
| Структура SEO-страниц | «Получи запросы “кухни на заказ” и предложи группы для отдельных страниц сайта». |
| Сезонное планирование | «Покажи помесячный спрос на “кондиционеры” за доступный завершённый период и выдели сезонные пики». |
| Перспективные регионы | «Сравни города по запросу “тепловой насос”. Покажи частотность и индекс интереса, затем предложи направления для дальнейшего исследования». |

Для подготовки рекламного задания начните с исходной фразы, уточните регион и устройства, затем попросите ИИ сгруппировать полученные запросы. Исследование дополнительных исходных фраз потребует дополнительных обращений к API.

## Подключение без программирования

1. [Зарегистрируйтесь или войдите в MCPKit](https://mcpkit.ru/mcp-wordstat). Одна учётная запись подходит для всех трёх сервисов.
2. По [инструкции Yandex Cloud](https://mcpkit.ru/instructions/wordstat/api-key) получите API-ключ и Folder ID, настройте необходимые права и оплату.
3. Сохраните их в [кабинете Wordstat](https://mcpkit.ru/mcp-wordstat/panel) и выберите активный аккаунт. Вводите ключ в кабинете, не отправляйте его в чат ИИ.
4. Скопируйте адрес сервера. Добавьте пользовательское MCP-подключение в ChatGPT, выберите **OAuth**, войдите в MCPKit и разрешите доступ.
5. Выберите подключение и спросите: **«Покажи доступные команды Wordstat».** Затем попробуйте запрос из таблицы выше.

**Адрес MCP-сервера:** `https://mcpkit.ru/mcp-wordstat/mcp`

Нужен ИИ-клиент и аккаунт с возможностью добавлять удалённые MCP-серверы через OAuth. Основные инструкции подготовлены для ChatGPT; настройка других совместимых клиентов может отличаться.

[Пошаговое подключение к ChatGPT с иллюстрациями](https://mcpkit.ru/instructions/wordstat/chatgpt).

## Доступность, стоимость и ограничения

Доступ к MCPKit сейчас бесплатный — условия опубликованы на [странице сервиса](https://mcpkit.ru/mcp-wordstat). Статистические запросы оплачиваются Яндексу отдельно; возможная подписка ИИ-клиента также оплачивается отдельно. Актуальные условия Yandex Cloud проверяйте при настройке оплаты.

Каждая статистическая команда принимает одну исходную фразу. В подборке популярных запросов можно запросить до 2 000 фраз; это не полная выгрузка всей семантики. Популярные запросы и региональное распределение относятся к последним 30 дням. Глубина истории и допустимые операторы зависят от периода динамики и правил Яндекса.

Частотность показывает спрос, а не число уникальных покупателей или продажи. Частотности пересекающихся запросов нельзя складывать как уникальную аудиторию. Сервис не предоставляет позиции сайта или гарантированную стоимость рекламы. Сервер не повторяет платные запросы автоматически.
